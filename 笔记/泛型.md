### 泛型方法的定义
```java

//<T>声明泛型类型，然后可以在参数，返回值中使用T
public <T> T mathodName(T param){
    return param;
}




```


### 为什么需要Class<T> type 参数
1. 反序列化时需要知道类型
 ```java
//假设我们从redis拿到JSON字符串
String json = "{\"name\":\"张三\",\"age\":18}";
//要转成对象，必须知道目标类型
User user = JSON.parseObject(json, User.class);  // 需要传入User.clas
//如果不知道类型，无法转换
```
2. 泛型在运行时会被擦除
```java
// Java的泛型是"伪泛型"，运行时类型信息会被擦除
public <T> T badMethod(String json) {
    // 编译后这里其实是 Object
    // 运行时不知道T是什么类型
    return JSON.parseObject(json, ?);  // 无法知道T的具体类型！
}

// 所以需要传入Class参数来保留类型信息
public <T> T goodMethod(String json, Class<T> clazz) {
    // clazz 在运行时存在，可以知道具体类型
    return JSON.parseObject(json, clazz);
}




```
